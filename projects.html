LectureLens

Ask questions across hours of YouTube lectures and get grounded answers with clickable timestamp citations that jump to the exact moment in the video.

  • Retrieval-augmented generation: transcripts from YouTube links or SRT / VTT captions are split into 30-second overlapping chunks, embedded with Gemini and stored in ChromaDB.
  • Hybrid retrieval fuses vector search and BM25 keyword search with Reciprocal Rank Fusion: 83% Hit@1 and 0.90 MRR on 24 labelled questions, vs 71% Hit@1 for semantic search alone.
  • Strict grounding prompt refused 6/6 out-of-scope questions; follow-up questions are rewritten into standalone queries; an embedded player jumps to each cited moment.
  • 78 offline pytest tests run on GitHub Actions CI, with typed settings and retries for transient API errors.

Movie Recommendation System

Pick a movie you like and get the 5 most similar movies from the TMDB 5000 dataset, using text features and cosine similarity.

  • Content-based filtering over 4,803 movies using genres, keywords, plot, tagline and production companies.
  • Text features turned into vectors with CountVectorizer; cosine similarity is precomputed once and cached for fast lookups.
  • Searchable movie dropdown in an interactive Streamlit web app.

AI-Powered Student Travel Planner

A Streamlit-based web page that turns a student's destination, trip length, budget and interests into a personalized, budget-aware day-by-day itinerary using Google Gemini.

  • Structured Gemini system prompt that returns a day-by-day morning / afternoon / evening plan with food, stay, transport, an estimated budget breakdown and student tips.
  • Input form for destination, 1–30 day duration, budget level, interests, accommodation type and special requirements, with required-field validation and automatic retry when the AI service is busy.
  • Deployed on Streamlit Community Cloud with the API key kept in encrypted secrets; reviewed by senior mentors as part of the internship.
